# Calculadora en Python

Este proyecto es una calculadora simple por consola, que permite realizar operaciones básicas entre dos números y una suma avanzada con múltiples valores.

## Estructura

- `main.py`: Ejecuta el menú de opciones.
- `sumar.py`: Contiene la función para sumar dos números.
- `resta.py`: Contiene la función para restar dos números.
- `multiplicacion.py`: Contiene la función para multiplicar dos números.
- `dividir.py`: Contiene la función para dividir dos números.
- `suma_avanzada.py`: Contiene la función para sumar una lista de números.

## ▶Cómo ejecutar

1. Clona el repositorio o descarga los archivos.
2. Asegúrate de tener Python instalado.
3. Desde la terminal, corre:

```bash
python main.py
